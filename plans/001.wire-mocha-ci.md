# 001 — Wire mocha and CI to a repo with no real tests

## Build order

1. Remove `test-pagination.js`, `test-balances-pagination.js`,
   `test-screener.js` (§1.1/§2.4).
2. Attempt mocha + chai first (the sweep's default) — hits the
   overrides/glob conflict in §3.1. Switch to `node:test` +
   `node:assert/strict` instead: no new devDependencies needed at all
   (`ts-node` was already present).
3. Add `test/placeholder.spec.ts` using `node:test`.
4. Add an npm `"test"` script:
   `TS_NODE_TRANSPILE_ONLY=1 node -r ts-node/register --test test/*.spec.ts`
   (matches `websocket-connector-sh`'s own `node:test` convention
   elsewhere in this sweep).
5. Add `.github/workflows/test.yml`: PR + push to `main` (default
   branch), Node 22, `npm ci`, `npm test`.
6. Verify `npm test` green locally.
